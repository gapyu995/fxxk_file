术语与规范

将 CSV、TSV 或 JSON 术语表放入 glossaries，下一批翻译会自动应用。

双文件对比

将两份同类型文件拖入右侧对比区，左右按页同步滚动，适合核对不同版本的差异。

操作提示
  • 文档与文档、图片与图片才能配对对比，不能混选。
  • 开启「同步滚动」后左右页面联动。
  • 图片对比按住右键拖动可平移，缩放范围 50%–300%。
  • 对比为只读查看，不会改动原文件。
图片转换

PNG → SVG 矢量化与 SVG → PNG 光栅化，全程在本机浏览器完成，图片不会上传到服务器。

使用提示
  • 图标 / Logo 用「色块轮廓」，线稿用「线段中心线」。
  • SVG 转 PNG 建议导出 2 倍以上尺寸，效果更清晰。
  • 白色背景的 Logo 可开启「移除背景色」。
  • 可直接把文件拖进右侧工具，或粘贴 SVG 代码。

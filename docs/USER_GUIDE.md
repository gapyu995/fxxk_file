# Translator 使用手册

本文档面向日常使用者，介绍从启动、模型配置、文档翻译到审校和导出的完整流程。

## 1. 启动和退出

最简单的方式是双击项目根目录的 `翻译脚本.cmd`。首次运行会自动创建 Python 虚拟环境并安装依赖，耗时取决于网络速度。以后启动通常会直接打开桌面窗口。

也可以运行 `start.ps1`，然后访问 <http://127.0.0.1:8765> 使用浏览器版。

请通过关闭桌面窗口或在 PowerShell 中按 `Ctrl+C` 正常退出。退出时程序会：

1. 停止尚未结束的翻译任务。
2. 把当前已经返回的部分译文写入 `output/`。
3. 清除 `workspace/` 中的任务记录。
4. 保留 `originals/` 中的原件和 `output/` 中的译文。

因此，重新启动后“最近文档”为空是正常行为，不代表原件或译文丢失。

## 2. 配置翻译接口

点击右上角“模型设置”。

### OpenAI 兼容 / CCSwitch

- 接口协议选择“OpenAI 兼容 / CCSwitch 网关”。
- 地址可填写基础地址，例如 `https://api.example.com/v1`，程序会补上 `/chat/completions`。
- 也可以直接填写以 `/chat/completions` 结尾的完整地址。
- 模型名称必须是网关实际支持的模型 ID。
- 云端服务通常需要 API Key；本地无鉴权网关可以留空。

### Anthropic Messages 兼容

- 接口协议选择“Anthropic Messages 兼容网关”。
- 地址可填写基础地址，也可填写以 `/messages` 结尾的完整地址。
- 填写相应模型名称和 API Key。

### 请求参数

- 每次最多段落数：范围 1–10，越大请求次数越少，但单次失败影响的段落更多。
- 单次最大原文字符数：范围 500–20000。超长段落会自动拆分，翻译后再合并。
- 失败自动重试次数：范围 0–10。超时、429、408/409/425 和部分 5xx 错误会指数退避重试。
- 使用系统代理：只有接口确实需要系统代理时才开启；本地网关通常应关闭。

HTTP 400、401、403、404 等地址、鉴权或请求配置错误通常不会反复重试，需要修改设置后重新翻译。

## 3. 上传文档

把文件拖到页面任意位置，或点击上传区域选择文件。支持同时选择多个文件。

支持格式：

| 格式 | 处理方式 | 注意事项 |
|---|---|---|
| DOCX | 直接提取并预览 | 支持正文和表格文字，复杂 Word 对象需复核 |
| DOC | LibreOffice 转换后处理 | 未安装 LibreOffice 时无法读取 |
| PDF | 直接提取文本 | 扫描件需要先 OCR，译文不保留 PDF 版式 |

单文件上限为 80 MB。上传成功后，原文件会以带任务 ID 的名称保存到 `originals/`，不会被译文覆盖。

“上传后立即翻译”默认勾选。若只想先检查分段、语言方向或模型设置，可取消勾选，上传后再点击“翻译空白段落”。

## 4. 语言方向和翻译

程序会依据前 30 个文本块自动判断中文或英文，并自动选择相反的目标语言。上传后仍可在工具栏手动修改源语言和目标语言。

点击“翻译空白段落”只会处理尚无译文且未锁定的段落，不覆盖已有内容。第一段会优先单独返回，随后按设置中的批量大小继续翻译，方便尽快开始审校。

如需修改已生成的段落，可直接人工编辑，或使用该段的重译操作。锁定的段落不会被批量翻译覆盖。

## 5. 两种审校视图

### 原件版面对照

左侧显示原始文件版面，右侧连续显示译文。适合参考标题、表格、图片和分页位置。

- 拖动中间分隔条调整宽度，双击恢复均分。
- 左侧可缩放原文预览。
- 右侧可调整译文字号。
- 开启“同步翻页”后，左右滚动会按照文档文字位置互相定位。
- 每个译文段落可按需展开对应原文。

PDF 预览采用按需渲染，超大文件不会一次载入全部页面。DOCX 由本地内置渲染器显示，不需要访问外部 CDN。

### 逐段精确对照

原文和译文严格按段并排，适合逐句核对。编辑或悬停时会突出显示整行，便于确认对应关系。

## 6. 编辑、保存和审校

直接在译文输入框中编辑。停止输入约 0.65 秒后，程序会自动保存任务状态，并重新生成 `output/` 中的译文文件。

常用段落操作包括：

- 重译：只重新调用模型翻译当前段落。
- 锁定/解锁：锁定后批量翻译不会改动该段。
- 标记已审校：记录该段已经人工确认。
- 展开原文：在连续译文视图中查看对应原文。

键盘快捷键：

| 快捷键 | 功能 |
|---|---|
| `Alt+↑` | 跳到上一段 |
| `Alt+↓` | 跳到下一段 |
| `Ctrl+Enter` | 将当前段标记为已审校 |

关闭程序前最好等待顶部状态显示“已保存”。桌面版正常关闭时也会主动提交当前编辑内容。

## 7. 下载和本地文件

点击“下载译文 DOCX”后，程序会先把最新内容写入 `output/`，再打开系统另存为窗口。无论是否在另存为窗口中选择其他位置，项目目录内都会保留一份输出文件。

默认文件名类似：

```text
原文件名_12位任务ID_译文.docx
```

对于 DOC/DOCX，译文从原文档副本生成，只替换已提取的文字节点，所以普通图片、表格、页眉页脚和大部分版式会保留。对于 PDF，程序创建新的 DOCX，并按顺序写入翻译后的段落。

## 8. 最近文档与删除

“最近文档”显示当前运行会话中的任务。点击记录旁的删除按钮只会移除工作区任务记录：

- 原件继续保留在 `originals/`。
- 已生成译文继续保留在 `output/`。
- 任务记录暂时移动到 `workspace/.trash/`，程序关闭时其中的状态文件会被清理。

这个删除操作不等于删除原文件或译文。如果需要彻底删除，请在确认文件无用后手动处理对应目录。

## 9. 术语表

程序会扫描 `glossaries/` 下的 CSV、TSV 和 JSON 文件，并只把当前批次原文中出现的相关术语发送给模型。文件修改后下一批请求就会读取新内容，无需重启。

CSV/TSV 字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `source` | 是 | 原语言术语 |
| `target` | 是 | 指定译法 |
| `source_lang` | 否 | `zh` 或 `en` |
| `target_lang` | 否 | `en` 或 `zh` |
| `domain` | 否 | 专业领域 |
| `notes` | 否 | 用法、上下文或禁用译法 |

示例：

```csv
source,target,source_lang,target_lang,domain,notes
术语表,glossary,zh,en,localization,统一使用 glossary
审校,review,zh,en,localization,不要使用 proofreading
```

JSON 示例：

```json
{
  "terms": [
    {
      "source": "术语表",
      "target": "glossary",
      "source_lang": "zh",
      "target_lang": "en",
      "domain": "localization",
      "notes": "统一译法"
    }
  ]
}
```

设置了语言方向的术语可自动反向使用。更多说明见项目中的 `glossaries/README.md`。

## 10. 风格指南

在 `glossaries/style_guide.md` 中写入项目级要求，例如：

```markdown
- 使用正式、简洁的商务英语。
- 标题采用 sentence case。
- 日期统一写作 YYYY-MM-DD。
- 产品名称 Translator 不翻译。
```

风格指南会随每批翻译请求发送给模型。建议使用短而明确、可以直接执行的规则，避免放入无关背景资料。

## 11. 故障排查

### 双击后没有窗口

在 PowerShell 中运行 `.\start.ps1` 查看错误信息。确认 Python 已安装，并且 `python --version` 可用。首次安装依赖需要可访问 Python 包源。

### 提示端口已被占用

关闭其他 Translator 窗口或占用 8765 端口的程序。也可以修改 `.env`：

```dotenv
APP_PORT=8766
```

### 模型设置显示已配置，但翻译失败

“已配置”只表示地址、模型名和协议已经填写，不代表接口连通。依次检查：

1. 协议是否与网关一致。
2. 地址是否包含正确的版本路径，如 `/v1`。
3. 模型 ID 是否存在且有权限。
4. API Key 是否正确。
5. 本地网关是否应关闭系统代理。

### 返回 429 或 5xx

程序会自动重试并在页面显示等待时间。持续出现 429 时，应降低批量大小、降低调用频率，或检查服务额度。

### PDF 提示没有可提取文字

文件很可能只有扫描图片。请先使用 Acrobat、ABBYY、OCRmyPDF 等工具添加文本层，再重新上传。

### DOC 无法读取或预览

安装 LibreOffice，或在 Word/WPS 中把文件另存为 DOCX。旧版 DOC 与 DOCX 是不同的文件格式，不能只修改扩展名。

### DOCX 译文出现版式差异

普通图片和段落样式会尽量保留，但图片内文字不做 OCR，文本框、批注、SmartArt、嵌入对象、复杂域等内容可能无法完整处理。最终交付前请在 Word/WPS 中人工复核。

### 重启后最近文档消失

这是当前程序的会话清理机制。请到 `originals/` 和 `output/` 查找保留的原件与译文。

## 12. 数据与安全

- 原件、译文、术语和配置保存在本机项目目录。
- 待翻译文本、匹配到的术语和风格指南会发送到所配置的模型服务。
- API Key 保存在 `.env`；请限制该文件的访问权限，不要上传到代码仓库或发送给他人。
- 服务默认仅监听 `127.0.0.1`。若改为局域网监听，应额外配置防火墙、反向代理认证和 HTTPS。

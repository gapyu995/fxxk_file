# fxxk_file 设计规范

面向「文档翻译」「双文件对比」「文件转换」「图片转换」「Markdown 查看」五个工作区。
所有取值以 `app/static/styles/tokens.css` 为准；本文解释**为什么是这些值**，并给出每个决策的使用边界。

配色直接对齐 DeepSeek Harness：**浅色取 Harness 原生浅色，深色取艾莲（Ellen）深色**，
因此本产品与 Harness 看起来是同一家族。

本文取代 `docs/FRONTEND_STRUCTURE.md` 中的样式与令牌小节，那一节只保留代码结构与模块职责。

---

## 1. 设计原则

1. **信息优先于装饰。** 这是高频文档工作台，不是营销页。不做渐变、纹理、毛玻璃。
2. **纯色 + 细描边表达层级。** 层级靠填充阶梯和 1px 发丝线，不靠投影堆叠。
3. **一个语义词表，两套配色。** 组件只写 `var(--color-*)`，切主题是换值不是换结构。
4. **动效解释变化，不装饰存在。** 只有"进入/离开/状态变化"配动画，悬停只用颜色过渡。
5. **尺度是封闭的。** 字号、字重、间距、圆角、动效时长只能取刻度内的值。
6. **阅读面铺满、操作面收敛。** 阅读类界面取消行长上限；操作类界面保持稳定行宽，
   避免指针在滚动中丢失目标。

## 2. 令牌架构（三层）

这是整套配色的骨架。**组件永远不直接引用色阶**，只引用语义别名。

```text
① 静态色阶    --static-*          原始色值，两套主题各自覆盖
        ↓
② 语义别名    --color-*           组件唯一允许引用的层
        ↓
③ 几何令牌    --space/radius/text/motion
```

**为什么分三层**：换主题只需覆盖①，②③不动；新增组件只需挑②里已有的语义。
若组件直接写色阶，`ellen` 这类换肤就变成全局搜索替换——Harness 用这层分离同时支撑
原生、艾莲两套皮肤与浅/深两个模式，共四张皮肤，组件代码零差异。

### 2.1 静态色阶

取自 Harness `design-platform.css` 的 `--dsw-static-*`，命名保持 `neutral-bluish` 的档位语义。

| 组 | 档位 | 用途 |
| --- | --- | --- |
| `--static-neutral-*` | 50/100/200/300/400/500/600/700/800/850/900 | 纯中性灰（滚动条） |
| `--static-ink-*` | 00/50/60/75/100/150/200/300/400/500/600/700/750/800/850/875/900/950/1000 | 蓝调中性（Harness `neutral-bluish`） |
| `--static-sea-*` | 50…900 | 艾莲·海蓝层级色（深色模式的交互与水色） |
| `--static-coral-*` | 50…900 | 艾莲·珊瑚强调色 |
| `--static-blue-*` | 50/500/600/900 | Harness 原生链接蓝 |
| `--static-amber-*` | 100/400/500/600/900 | 警告 |
| `--static-red-*` | 50/100/400/500/600/900 | 错误 |
| `--static-green-*` | 100/400/500/900 | 成功 |

## 3. 色彩使用规则

- 对比度下限 **4.5:1**（正文）/ **3:1**（≥18px 或加粗）。`--color-faint` 只用于占位符与图标。
- 状态不只用颜色：段落状态、文档状态、保存状态都同时有文字。
- 深色模式下**不依赖阴影**表达层级（阴影在深色下近乎不可见），层级完全由填充阶梯承担。
- 禁止在画布上叠背景图/网格/渐变。

## 4. 字体排印

### 4.1 字阶（封闭，**下限 12px**）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--text-caption` | **12px** | 标签、说明、表格辅助信息、状态统计 |
| `--text-detail` | 13px | 表格正文、字段值、按钮 |
| `--text-body` | 14px | 默认正文、表单 |
| `--text-subhead` | 16px | 卡片标题、区块标题 |
| `--text-heading` | 20px | 对话框标题、移动端页面标题 |
| `--text-title` | 24px | 页面标题 |
| `--text-display` | `clamp(26px, 3.4vw, 34px)` | Markdown `h1` |

**最小字号 12px，没有例外。** 10.5px/11px 的中文在 100% 缩放的 Windows 上标点会糊成
一条灰带。需要更弱的视觉权重时改**颜色**（`--color-muted` → `--color-faint`）或**字重**，
不要改字号。`body` 基准 14px。

### 4.2 字重（两档 + 默认）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--weight-medium` | 500 | 导航选中项、按钮、标签、关键字段 |
| `--weight-semibold` | 600 | 页面标题、卡片标题、表头、指标数值 |

正文用 400 但**不显式声明**。不再使用 550/650/700 —— 中间字重在非可变字体上
跨平台渲染不可预测（Harness 把 Figma 的 510 规范化为 500，同因）。

### 4.3 字族

| Token | 用途 |
| --- | --- |
| `--font-sans` | 全站默认（含中文回退 PingFang SC / Microsoft YaHei） |
| `--font-doc` | **只读**文档正文：原文格、Markdown 正文 |
| `--font-mono` | 标识符、代码块、转换结果、编码名 |

等宽栈以 `Courier / PingFang SC / Microsoft YaHei` 收尾，避免 Windows 中文回退到 SimSun。
原文与译文必须用不同字族（衬线 vs 无衬线），并排审校时才分得清哪侧是原文。

### 4.4 图标字号（与文字分开）

`--icon-sm`(13) / `--icon-md`(16) / `--icon-lg`(20) / `--icon-xl`(40)。
图标按控件尺寸取值，不借用文字阶梯。

## 5. 间距、圆角与阴影

### 5.1 间距刻度

`--space-1`(4) `2`(8) `3`(12) `4`(16) `5`(24) `6`(32)

行内 4/8 · 控件间 8 · 卡片内 12/16 · 卡片间 12/16 · 页面级 24/32。
1–3px 与百分比是发丝级调整（描边偏移、进度条高度），不属于刻度。

### 5.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-xs` | 4px | 高亮、内嵌小方块 |
| `--radius-sm` | 8px | 按钮、输入框、导航条目、代码块 |
| `--radius-md` | 12px | 卡片、面板、表格容器、下拉菜单 |
| `--radius-lg` | 16px | 对话框 |
| `--radius-pill` | 999px | 徽标、胶囊、圆点计数 |

`50%` 保留给真正的圆形（状态点、序号圆点）。

### 5.3 阴影（三档，克制）

| Token | 浅色 | 用途 |
| --- | --- | --- |
| `--shadow-subtle` | `0 2px 4px rgba(0,0,0,.05)` | 几乎不用 |
| `--shadow-popover` | `0 8px 24px rgba(0,0,0,.10)` | 下拉、气泡 |
| `--shadow-prominent` | `0 16px 48px rgba(0,0,0,.16)` | 弹窗、抽屉 |

**卡片不用阴影**，只用 1px 描边与填充阶梯。

## 6. 动效

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ease-standard` | `cubic-bezier(.4,0,.2,1)` | 全部过渡（对齐 Harness `--ds-ease-in-out`） |
| `--motion-fast` | 150ms | 颜色、背景、描边、不透明度 |
| `--motion-base` | 200ms | 尺寸、布局（对齐 Harness `--ds-transition-duration`） |
| `--motion-slow` | 300ms | 面板展开、侧栏折叠 |
| `--motion-pulse` | 900ms | **唯一**循环动画：进行中状态点 |

- 该有动效：悬停/激活 150ms；侧栏折叠 300ms；菜单展开 150ms；进行中脉冲。
- **不该有动效**：悬浮卡片的 `translateY`、表格行位移、常态元素的循环动画、
  对话框遮罩的 `backdrop-filter`、分割条拖动（跟手感来自无过渡）。
- `prefers-reduced-motion: reduce` 是独立的系统级设置，全站动画降到 1ms。

## 7. 布局

### 7.1 骨架

**侧栏切换功能，顶栏切换页面。** 这是 Harness 的双层导航：一级（功能）在侧栏，
二级（页面/视图）在顶栏，两级职责不重叠。

```text
┌ 顶栏 56px ────────────────────────────────────────────────────┐
│ 折叠按钮 │ 页面切换（当前功能的视图）│ … 文档搜索 · 保存 · 设置 │
├ 侧栏 240/64 ─┬────────────────────────────────────────────────┤
│ 文档翻译      │                                                │
│ 双文件对比    │  当前页面内容                                   │
│ 文件转换      │                                                │
│ 图片转换      │                                                │
│ Markdown 查看 │                                                │
│ ─────────    │                                                │
│ ☾ 主题  设置  │                                                │
└──────────────┴────────────────────────────────────────────────┘
```

- **侧栏 = 功能切换**：五个功能各一条，图标 + 文字；选中项用 `--color-accent-soft` 填充
  + `--weight-medium`。底部固定主题开关与模型设置（全局项，不随功能变化）。
- **顶栏 = 页面切换 + 相关调整按钮**：左侧是当前功能的视图/页面切换（如文档翻译的
  「原件版面对照 / 逐段精确对照」），右侧是全局控件（文档搜索、保存状态、设置）。
- 功能的**局部操作**（翻译空白段落、重译全文、导出等）留在页面自身的工具栏，
  不挤进顶栏——顶栏只放跨页面成立的东西。

### 7.2 侧栏折叠

- 宽度 `240px` ↔ `64px`，切换按钮在顶栏最左；过渡用 `--motion-slow`。
- 折叠态只留图标，文字以 `title` + `aria-label` 提供；选中态由左侧 2px 指示条表达。
- 状态写入 `fxxk_file.preferences.sidebarCollapsed`，首屏由 `index.html` 内联脚本落地，
  避免刷新时先展开再收起。
- ≤720px 时侧栏默认折叠为图标条，不隐藏（功能切换必须始终可达）。

### 7.3 页面内骨架

```text
┌ 页面工具栏 52px：标题 + 局部操作（按意图分组，组间 1px 竖线）─┐
├ 主体 ────────────────────────────────────────────────────────┤
│  原文窗格 │ 6px 分隔条 │ 译文窗格                              │
│  吸顶：窗格头 → 筛选栏 → 列头 → 段落行                        │
└──────────────────────────────────────────────────────────────┘
```

### 7.4 吸顶偏移

译文区三层吸顶必须手工对齐，新增一层要同步改后面所有层：

| 层 | `top` | `z-index` |
| --- | --- | --- |
| 窗格头 | 0 | 4 |
| 筛选栏 | 36px | 3 |
| 列头 | 70px | 2 |

Markdown 阅读区**只有一层吸顶**（在 `#markdownContent` 这个滚动容器内）：

| 层 | `top` | `z-index` |
| --- | --- | --- |
| 表格头（`thead` / `thead th`） | 0 | 2 |
| 章节标题（`h2`–`h6`） | 不吸顶（`position: static`） | — |

**章节标题故意不吸顶。** 所有标题如果都吸在同一个 `top`，只要两节同时进入视口就会
叠在一起，看起来像文字压字——这不是"当前章节指示"，是渲染错误。当前读到哪一节由
**左侧目录**表达（高亮 + 节名 + 进度条），阅读列不重复第二遍。

**表格头吸在 `top: 0`。** 它只在所属表格还在视口内时有效，表格滚过去后自然让位，
因此不会有第二个元素和它抢同一条带子。

> 曾经的反例（勿重复）：标题写了 `position: sticky` 而漏写 `top`，于是它粘在自然位置
> （等同 `static`，永不吸顶），而表格头仍按标题高度预留了偏移量——表格头上方空出一条
> 带子，带子里本该显示的标题并没有钉住。**吸顶元素必须显式写 `top`，不吸顶的元素就
> 一个 `sticky` 都不要写**，不要留"半吸顶"状态。

### 7.5 z-index 阶梯（封闭）

| 值 | 用途 |
| --- | --- |
| 2–4 | 工作区内吸顶层次 |
| 6 | 全屏工作区覆盖主区 |
| 8 | 工具栏内下拉菜单 |
| 20 | 顶栏 |
| 25 | 拖拽遮罩 |
| 30 | toast |

对话框走浏览器 top layer，不需要 `z-index`。

### 7.6 可调宽度

统一交互：拖动、双击复位、方向键微调、`role="separator"`、拖动时 `body` 加
`resizing-*` 类（`cursor: col-resize` + `user-select: none`）。

| 分隔条 | 范围 | 双击 |
| --- | --- | --- |
| 原文/译文 | 30%–70% | 恢复 50% |
| Markdown 目录 | 140–420px | 恢复 196px |

**一个控件只做一件事。** 显示/隐藏与尺寸调节是两种意图，必须分开承载：

| 意图 | 控件 | 形态 |
| --- | --- | --- |
| 显示 / 隐藏 Markdown 目录 | `.markdown-toolbar` 里的 `#markdownTocToggle` 按钮，或 `Ctrl+\` | 二值，`aria-pressed` |
| 调整 Markdown 目录宽度 | 正文左侧 6px 的 `#markdownTocSplitter` | 连续，拖到 140px 即停 |

分隔条**不承担隐藏职责**：拖到最左只夹到最小宽度，不会把目录拖没；目录隐藏后分隔条
一并 `display: none`（它的唯一职责是调整一个可见列的宽度）。同理，折叠**不重置宽度**——
再次显示时回到上次的宽度。宽度与可见性分别存 `markdownTocWidth` / `markdownTocVisible`。

### 7.7 断点

| 宽度 | 变化 |
| --- | --- |
| ≤1180px | 文档工具栏改纵向两行；转换区结果栏移到下方 |
| ≤980px | 侧栏折叠为 64px 图标条；段落行序号列 34px |
| ≤720px | 侧栏保持图标条；顶栏 52px；工具栏按钮拉满宽度 |

容器查询用于窗格内部判断（与窗口宽度无关）。

## 8. 组件约定

| 组件 | 约定 |
| --- | --- |
| `.button` | 32px 高、`--weight-medium`、`--radius-sm`；`.primary` 主色填充、`.subtle` 无边框、`.danger` 危险色软底 |
| `.icon-button` | 28px 方块、透明底、`--color-muted` 图标；**必须有 `aria-label`** |
| `.chip` | 胶囊徽标，四语义变体 |
| 导航条目 | 高 36px、`--radius-sm`、左 2px 选中指示条 |
| 对话框 | 三段式：头部（固定）+ 主体（唯一滚动区）+ 操作条（固定） |
| `.toast` | 右下角固定、`--color-inverse` 底、左侧 3px 语义色条 |
| `.segment-row` | `40px minmax(200px,1fr) minmax(200px,1fr) 40px`；状态由译文格左 2px 规则条表达 |

### 对话框三段式（强制）

`dialog[open]` 为 flex 纵向，`max-height: calc(100dvh - 48px)`；只有 `.dialog-body` 滚动；
表单用 `.dialog-form`（flex 纵向、`min-height: 0`）承载。

### Markdown 目录的当前位置（**新增**）

目录必须回答"我现在读到哪一节"，这是它的主要职责，不只是跳转列表：

- 滚动时按滚动位置计算当前标题（视口顶部之上最近的一个），命中项加 `.active`：
  `--color-accent-soft` 填充 + `--color-link` 文字 + 左侧 2px 指示条。
- 当前标题名同时显示在目录头部（`#markdownTocCurrent`），目录收起时也能读到位置。
- 长文档中当前项若超出目录可视区，目录自身滚动使其可见（`scrollIntoView({block:'nearest'})`）。
- 阅读进度用一条 2px 进度条画在目录右缘，高度 = 滚动比例 × 目录高度。
- 未滚动（在文首）时高亮第一个标题，不出现"无高亮"状态。
- 高亮由滚动位置推导，**不记"最后点击的那一项"**：用键盘、搜索或目录跳转到达某节时，
  高亮同样正确。

---

## 9. 无障碍

- 对比度 ≥ 4.5:1（正文）/ ≥ 3:1（≥18px 或加粗）；最小字号 12px。
- 所有图标按钮必须有 `aria-label`；折叠态侧栏条目用 `title` 补全文字。
- 主题三态（跟随系统/浅色/深色）用 `aria-pressed`；`<html data-theme>` 同时设置 `color-scheme`。
- 焦点环统一 2px `--color-primary`，`outline-offset: 2px`。
- 分隔条支持方向键（`Shift` 加速）；`Esc` 关闭；`?` 打开快捷键面板。

## 10. 规范如何被强制

**静态检查**（`.tmp/integration/token-check.py`，接入 CI，无第三方依赖）：

| 检查项 | 判定 |
| --- | --- |
| 未定义令牌 | 功能样式表出现 `var(--x)` 而 `tokens.css` 未定义 → 失败 |
| 硬编码颜色 | `tokens.css` 外出现 hex 或 `rgba()` → 失败 |
| 封闭尺度 | `font-size`/`font-weight`/`border-radius` 不是令牌/clamp → 失败 |
| 字号下限 | 文本令牌 < 12px → 失败 |
| 动效时长 | `transition`/`animation` 出现字面时长 → 失败 |
| 未消费令牌 | `tokens.css` 定义的令牌无人引用 → 失败 |
| 色阶直用 | 组件样式表出现 `var(--static-*)` → 失败（必须走语义别名） |

**浏览器检查**（`.tmp/integration/`）：

| 约束 | 手段 |
| --- | --- |
| 3 视口无横向溢出、无控制台异常 | `visual-pass.mjs` |
| 对话框在 560px 高窗口内主体滚动、操作条可见 | `layout-audit.mjs` |
| Markdown 正文铺满、目录可拖拽、当前标题高亮 | `markdown-layout.mjs` / `toc-splitter.mjs` |
| 两套主题对比度 ≥ 4.5:1、切换与持久化 | `theme-check.mjs` |

改动样式后的执行顺序：

```powershell
python .tmp/integration/token-check.py
node .tmp/integration/theme-check.mjs
node .tmp/integration/visual-pass.mjs 1440 900 local
python -m pytest tests -q
```

## 11. 已知偏离

1. **Markdown 正文没有行长上限**（用户要求铺满窗口）。若后续需要"舒适行长"，
   应作为可选开关加入，而不是改默认值。
2. **译文正文默认 16px**，由 A−/A＋ 在 14–22px 间调节，用独立的
   `--translation-font-size`；原文格固定 `--source-font-size`(14px)。
3. **`--md-scale` 由 Markdown 缩放控件覆盖**（0.8–1.4），是唯一允许的运行期字号覆盖。
4. **Markdown 内的 `em` 字号**（`code` 0.88em、表格 0.92em）随正文缩放，不参与字阶校验。
5. **图片转换工作区是 iframe**，由 `app/static/tools/image-convert/*.html` 自带样式，
   尚未接入本规范的语义别名层；其配色需单独对齐。
